## 关卡数据结构（js/levels.js）

```js
// js/levels.js 内部（IIFE 私有作用域）
const LEVELS = {
  html: [ { /* level 1 */ } ],
  css:  [ { /* level 1 */ } ],
  // ... 9 种语言，每语言 1 关
};
// 对外暴露：window.LevelsRuntime = Runtime

// 单关结构：
{
  id: 'html-1', langId: 'html', index: 1,
  title: '黑暗房间', subtitle: 'Dark Room',
  narrative: '游戏化任务叙述',
  knowledge: ['知识点1','知识点2'],
  starterCode: '<!-- 初始脚手架 -->',
  solution: '<h1>光</h1>',
  hint: '解题提示',
  buildPreview: (code) => `<!DOCTYPE html>...${code}...`,  // 控制 iframe 内容
  check: (code, doc, win) => ({ passed: true, message: '反馈' })  // doc=iframe 文档
}
```

`buildPreview(code)` 是关键：每关完全控制 iframe 内容。
- HTML/CSS/JS：真实执行（iframe 直接渲染用户代码 + 主题样式）。
- Python/Java/C++/C#：模拟执行（正则解析用户代码片段驱动预置游戏场景动画）。
- Vue/Uni-app：预置迷你响应式引擎（Proxy）/ 手机 mockup。

## Portal 过渡动画（核心体验）

点击"开始之旅"后：
1. t=0：`spawnClickEffect` 粒子爆发（已有）+ 创建 `.portal-overlay`（初始=卡片 boundingRect，主题色渐变+发光）。
2. t=0：overlay 加 `.expanding` → CSS transition 扩展到全屏（0.55s，`cubic-bezier(0.7,0,0.2,1)`，与现有两屏切换同款）。
3. t=300：`navigateTo('#levels/...')` → 关卡页在 overlay 后渲染（被遮住）。
4. t=560：overlay 加 `.fading` → 淡出（0.3s），关卡内容 stagger 入场动画自然显露。
5. t=900：移除 overlay。全程 ~850ms，无空白帧。

视觉效果：主题色色块"吞掉"屏幕揭幕关卡，粒子在前承接，缓动手感统一。
