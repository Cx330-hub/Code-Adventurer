# CodeAdventurer 代码冒险者 — 产品需求文档 (PRD)

## 1. 产品概述

CodeAdventurer 是一款面向编程零基础用户的**多语言闯关式编程学习平台**。以游戏化闯关方式，帮助用户从零开始学习 HTML、CSS、JavaScript、Python、Vue、Java、C/C++、C#、Uni-app 共 **9 种**主流编程语言。

- **核心价值**：将枯燥的编程学习转化为"看知识点 → 写代码 → 实时预览 → 自动通关"的游戏式体验，降低入门门槛
- **目标用户**：编程零基础的青少年、转行学习者、自学编程爱好者
- **产品定位**：轻量级、多语言、可扩展的编程闯关学习工具

> **当前实现状态**：首页（品牌屏 + 语言选择器）已实现并接入 `index.html`；关卡列表页、闯关练习页尚未实现。`js/levels.js` 已含 9 种语言各 1 个首关的数据与运行时，但尚未接入页面。

## 2. 核心功能

### 2.1 功能模块

1. **首页（语言选择页）**：炫酷动态背景、语言卡片选择、学习数据概览 —— **已实现**
2. **关卡列表页**：所选语言的全部关卡、进度追踪、难度标识 —— **规划中（未实现）**
3. **闯关练习页**：知识点面板、代码编辑器、实时预览、判题系统 —— **规划中（未实现，`levels.js` 运行时已编写）**

## 3. 核心流程

**已实现**：用户进入首页 → 预加载动画 → 品牌屏 → 语言选择器 → 选择语言。

**规划中**：选择语言后 → 进入关卡页 → 阅读知识点 → 编写代码 → 运行预览 → 检查答案 → 通关解锁下一关。

## 4. 用户界面设计

### 4.1 设计风格

- **整体风格**：深色科技风 + 赛博朋克感，强调霓虹光效和动态视觉
- **主色调**：深海军蓝 `#0a0e27` → 紫罗兰渐变 `#667eea` → 霓虹绿 `#00f5a0`
- **辅助色**：霓虹粉 `#ff6b9d`、电蓝 `#4facfe`、金色 `#ffd700`
- **字体**：标题使用 `Orbitron` 科幻字体，正文使用 `JetBrains Mono` 等宽字体（通过 CSS `@import` 引入，离线回退系统字体）
- **按钮风格**：霓虹发光边框 + 圆角 + 悬停流光效果
- **卡片风格**：毛玻璃拟态（Glassmorphism）+ 动态光效边框
- **图标风格**：emoji + SVG 线性图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 首页 | 动态背景 | Canvas 粒子连线 + 渐变光斑 |
| 首页 | 品牌标题 | 渐变文字 + 发光阴影 + 字间距动画 |
| 首页 | 语言卡片 | 毛玻璃背景 + 抽屉式 3D 层叠 + 语言专属配色光效 |
| 首页 | 进度统计 | 进度条 + 数字滚动动画 |
| 闯关练习页 | 编辑器 | 深色主题 + textarea（规划中，无语法高亮） |

### 4.3 响应式设计

- **桌面优先**：首先针对 1920×1080 及以上分辨率优化
- **平板适配**：1024×768 分辨率，布局自适应缩放
- **移动适配**：后续版本支持，当前阶段专注桌面端

### 4.4 动效规范

- 页面加载：元素 staggered reveal（错落淡入），间隔 80ms
- 卡片悬停：3D 倾斜 + 光晕扫过 + 轻微浮起
- 按钮交互：按下缩放 0.95 + 发光增强
- 背景动画：粒子缓慢漂移 + 连线脉动 + 光斑移动
- 过渡时长：200ms-400ms，使用 ease-out 曲线
